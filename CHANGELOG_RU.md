# История изменений VEYRA

## 1.0.0 — первое ядро языка 1.0

- Добавлены массивы: литералы `[]`, индексация с нуля, присваивание по индексу и вложенные массивы.
- Добавлена библиотека `list.len`, `list.push`, `list.pop`, `list.get`, `list.set`, `list.clear`.
- Добавлены проверки типа индекса, целочисленности, границ и пустого массива для `pop`.
- Циклические ссылки между массивами отклоняются при добавлении/назначении.
- Версия runtime и CLI обновлена до `1.0.0`.
- Обновлены английская и русская документация и спецификация.
- Расширены тесты на массивы, вложенную индексацию, выход за границы, дробный индекс, пустой `pop` и циклы ссылок.
- Добавлен GitHub Actions workflow для сборки и тестов на Linux.

## 0.2.0 — ядро языка и ограничения

- Добавлены `const`, `for`, `break`, `continue` и локальные области видимости.
- Добавлены `text.*`, `math.*`, сведения о Linux и проверки метаданных файлов.
- Добавлены `--check` и `--builtins`.
- SHA-256 ограничивает чтение 256 MiB и не следует за конечной символической ссылкой.
- Добавлены ограничения ресурсов и усиленные флаги сборки Linux.
- Уточнено: VEYRA не является sandbox или сертифицированной защитной системой.
