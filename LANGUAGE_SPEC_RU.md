# Спецификация ядра VEYRA 1.0.0

## Основные правила

- Исходные файлы используют расширение `.vey`.
- Идентификаторы ASCII и регистрозависимы.
- Комментарии: `# до конца строки` или `// до конца строки`.
- Точка с запятой необязательна после простых инструкций; в заголовке `for` она разделяет секции.

## Значения

| Тип | Пример | Примечание |
|---|---|---|
| number | `10`, `3.14` | `double`; NaN/Infinity от операций отвергаются |
| string | `"hello"` | byte string; `text.len` считает байты |
| bool | `true`, `false` | логическое значение |
| none | `none` | отсутствие значения |
| array | `[1, "x", true]` | изменяемый массив, максимум 100 000 элементов |

`const name = ...` запрещает переназначение имени, но не замораживает содержимое массива.

## Операторы

- Унарные: `!`, `-`.
- Арифметика: `+ - * / %`.
- Сравнение: `== != < > <= >=`.
- Логика: `&& ||` с коротким замыканием.

`+` выполняет числовое сложение, если оба операнда не являются строками; если хотя бы один — строка, значения преобразуются в строки и объединяются. Сравнение массивов через `==` проверяет идентичность массива, а не поэлементное равенство.

## Инструкции

Поддерживаются `let`, `const`, присваивание, `print`, `if/else`, `while`, C-style `for`, `break`, `continue`, `fn`, `return` и expression statements. Объявление имени повторно в одной области завершается ошибкой. Блоки создают локальные области. Замыкания не реализованы.

## Массивы

```vey
let values = [10, 20, 30];
print values[0];
values[1] = 25;
list.push(values, 40);
print list.len(values);
```

Индекс начинается с нуля и должен быть целым неотрицательным числом в пределах массива. Вложенная индексация поддерживается: `matrix[1][0]`. Циклические ссылки через присваивание элемента и `list.push`/`list.set` запрещены.

| Функция | Поведение |
|---|---|
| `list.len(a)` | длина |
| `list.push(a, v)` | добавить элемент, вернуть новую длину |
| `list.pop(a)` | удалить/вернуть последний элемент; ошибка для пустого массива |
| `list.get(a, i)` | прочитать элемент с проверкой границ |
| `list.set(a, i, v)` | заменить элемент, вернуть значение |
| `list.clear(a)` | очистить массив, вернуть `none` |

## Встроенные группы

Список, соответствующий бинарнику, выдаёт `veyra --builtins`.

- `text.*`: `len`, `lower`, `upper`, `trim`, `contains`, `starts_with`, `ends_with`.
- `math.*`: `abs`, `floor`, `ceil`, `round`, `sqrt`, `min`, `max`, `pow`.
- `linux.*`: `os`, `kernel`, `arch`, `hostname`, `pid`, `page_size`.
- `system.cwd()`.
- `security.*`: UID/root, доступность путей, тип/права/размер/владелец, аудит метаданных и SHA-256.

`security.sha256` не следует за конечной символической ссылкой, проверяет открытый дескриптор на обычный файл и ограничивает чтение 256 MiB.

## CLI

- `veyra file.vey` — исполнение.
- `veyra --check file.vey` — разбор без исполнения; не полный статический анализ.
- `veyra --builtins` — список функций.
- `veyra --version` — версия.
- `veyra --help` — справка и лимиты.

## Лимиты

| Ресурс | Лимит |
|---|---:|
| исходник | 4 MiB |
| токены | 250 000 |
| глубина разбора | 256 |
| длина строки | 4 MiB |
| общий вывод | 16 MiB |
| итерации циклов | 1 000 000 |
| инструкции | 5 000 000 |
| вычисления выражений | 20 000 000 |
| глубина вызовов | 256 |
| элементов массива | 100 000 на массив |
| файл для SHA-256 | 256 MiB |

Лимиты уменьшают вероятность случайного исчерпания ресурсов, но не делают недоверенный код безопасным.
