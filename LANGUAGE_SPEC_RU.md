# Мини-спецификация VEYRA 0.2.0

## Общие правила

- Кодировка исходников: UTF-8 рекомендуется; идентификаторы в текущей версии ASCII.
- Расширение исходного файла: `.vey`.
- Комментарии: `# до конца строки` или `// до конца строки`.
- Точка с запятой допускается после простых инструкций; в заголовке `for` обязательна.
- Имена регистрозависимы: `count` и `Count` — разные имена.

## Типы значений

| Тип | Примеры |
|---|---|
| number | `0`, `-12`, `3.14` |
| string | `"hello"`, `'world'`, `"line\\n2"` |
| bool | `true`, `false` |
| none | `none` |

Числа представлены `double`; операции, возвращающие бесконечность или NaN, завершаются ошибкой. Строки хранят UTF-8/байты, но `text.len` считает байты, а функции регистра меняют только ASCII.

## Инструкции

```vey
let name = "Abduali";       # изменяемая переменная
const api_level = 2;         # неизменяемое значение
name = "Veyra";

print name;

if (api_level >= 2) {
    print "supported";
} else {
    print "unsupported";
}

let n = 0;
while (n < 3) {
    n = n + 1;
}

for (let i = 0; i < 10; i = i + 1) {
    if (i == 2) { continue; }
    if (i == 7) { break; }
    print i;
}

fn add(a, b) {
    return a + b;
}
print add(2, 3);
```

`let` и `const` не могут повторно объявлять имя в той же области. Блоки `if`, `while` и `for` создают локальную область видимости; присваивание найденной переменной меняет соответствующую внешнюю привязку. `break` и `continue` действуют только на цикл текущей функции. Функции поддерживают рекурсию, но имеют предел глубины.

## Операторы

- Арифметика: `+ - * / %`; деление и остаток от нуля — ошибка.
- Сравнение: `== != < > <= >=`.
- Логика: `&& || !` с коротким замыканием.
- Скобки `()` меняют приоритет операций.
- `+` конкатенирует, если хотя бы один операнд — строка; иначе складывает числа.

## Ограничения runtime

Размер файла до 4 MiB; до 250 000 токенов; глубина разбора 256; глубина пользовательских вызовов 256; до 1 000 000 итераций циклов; до 5 000 000 выполненных инструкций и 20 000 000 вычислений выражений; строка до 4 MiB; stdout до 16 MiB; SHA-256 — обычный файл до 256 MiB.

## Статус

Документ описывает текущий прототип, а не обещает стабильную совместимость ABI. Здесь нет типового компилятора, массива/словаря, импорта модулей, обработки исключений на уровне языка или гарантированной изоляции процесса.
