# Язык программирования VEYRA

**VEYRA 1.0.0** — Linux-ориентированный язык с расширением `.vey` и интерпретатором на C++20. Первый релиз ветки 1.0 закрепляет компактное ядро для обучения программированию, небольших программ и read-only проверок информации о Linux.

> **Статус:** первый релиз ядра языка 1.0, развитие продолжается. VEYRA не является сертифицированной защитной системой или песочницей. Не запускай недоверенный код и не используй `sudo` для обычных программ.

## Возможности

- Переменные `let`, привязки `const`, числа, строки, логические значения и `none`.
- Изменяемые массивы, вложенные массивы, индексация и присваивание по индексу.
- Арифметика, сравнения, логические операторы с коротким замыканием.
- `if/else`, `while`, `for`, `break`, `continue`.
- Функции `fn`, параметры, `return` и рекурсия.
- Области видимости блоков.
- Стандартные функции `text.*`, `math.*`, `list.*`.
- Сведения о Linux и проверки метаданных файлов через `linux.*`, `system.cwd()`, `security.*`.
- `--check`, `--builtins`, лимиты ресурсов, регрессионные тесты и Linux CI.

```bash
git clone https://github.com/veyra-linux/veyra-language.git
cd veyra-language
make clean
make -j2
make test
```

Успешный запуск завершается строкой `VEYRA tests: OK`.

Установка:

```bash
sudo make install
veyra --version
```

## Массивы в VEYRA 1.0

Массивы индексируются с нуля, изменяемы, могут содержать разные типы и другие массивы. Лимит — 100 000 элементов на массив.

```vey
let numbers = [10, 20, 30];
numbers[1] = 25;
list.push(numbers, 40);

print numbers;                    # [10, 25, 30, 40]
print numbers[0];                 # 10
print list.len(numbers);          # 4
print list.get(numbers, 2);       # 30
print list.pop(numbers);          # 40

let matrix = [[1, 2], [3, 4]];
matrix[1][0] = 9;
print matrix;                     # [[1, 2], [9, 4]]
```

Индекс должен быть неотрицательным целым числом в границах массива. `list.push` возвращает новую длину; `list.pop` извлекает последний элемент и сообщает ошибку для пустого массива; `list.set` заменяет элемент; `list.clear` очищает массив. Циклические ссылки запрещены.

Функции: `list.len(array)`, `list.push(array, value)`, `list.pop(array)`, `list.get(array, index)`, `list.set(array, index, value)`, `list.clear(array)`.

Важно: `const` запрещает переназначить имя, но пока не замораживает массив — его элементы можно менять.

## Стандартная библиотека

- `text.*`: длина строки в байтах, ASCII-регистр, trim, contains, starts_with, ends_with.
- `math.*`: abs, floor, ceil, round, sqrt, min, max, pow.
- `list.*`: операции с массивами.
- `linux.*`: ОС, версия ядра, архитектура, hostname, PID, размер страницы.
- `system.cwd()`: текущий каталог.
- `security.*`: UID/root, доступность путей, тип/права/размер/владелец файла, базовый аудит метаданных и SHA-256.

`security.sha256(path)` хеширует только обычные файлы, не следует за конечной символической ссылкой и ограничивает чтение 256 MiB.

## Команды

```text
veyra <file.vey>       Запустить программу
veyra --check <file>   Проверить синтаксис без исполнения
veyra --builtins       Показать встроенные функции
veyra --version        Показать версию
veyra --help           Показать справку и лимиты
```

`--check` не является полным статическим анализатором.

## Безопасность

VEYRA **не является песочницей**. Программа получает права пользователя, запустившего интерпретатор. В стандартной библиотеке нет общего запуска shell-команд, произвольной записи файлов или сетевого API, но доступны сведения о системе, метаданные файлов и чтение для хеширования. Запускай только доверенные программы; для недоверенного кода нужна отдельная системная изоляция Linux.

Официальный runtime использует Linux API. Сам `.vey` — текстовый файл, поэтому сторонний разработчик может создать другой интерпретатор или запускать Linux через VM/WSL.
